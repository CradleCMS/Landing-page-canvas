# Landing page template

Designed to be used when prompting landing pages with AI or using premade landing pages.

> [Guide on how to work with the theme in Cradle CMS](https://cradlecms.com/blog/guides/article/redesign-a-site-with-ai)

## Templates

* Index page : empty file for adding landing page content

Ready made templates for other types of content

* Page templates
* Blog and Article templates
* 404 page
* Closed site template to display while building

## Features
* Minimal CSS approach.
* Open graph tags.
* Styled asides in articles written in Markdown.
* Styled fotnotes created with Markdown.
* Color settings
